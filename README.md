# 楽譜PDF補正

スキャンした楽譜PDFを補正して A4 縦の PDF に書き出す、ブラウザだけで動く自分用ツール。
ファイルはどこにも送信されない(処理はすべてブラウザ内)。

公開URL: https://secidoire.github.io/music_sheet_tools/

## 機能

- PDF・画像(JPG/PNG など、ブラウザが読める形式)をドラッグ&ドロップ(または「ファイルを選択」)で読み込み。
  複数ファイルはファイル名順(数字は数値順)に1つの文書としてまとめる。
  写真の EXIF の向きは反映する
- 大きさの推定: 画像の解像度や PDF のページサイズは当てにならない(写真・切り抜き・スキャナ設定の誤り)ため、
  五線の間隔(縦方向の黒と白の連続の長さの最頻値)を測り、どのページも五線の間隔 1.6mm とみなして処理する。
  ミリ単位の検出のしきい値と、短いページを拡大しすぎない上限(出力の五線の間隔で 2.0mm まで)はこの尺度で決まる。
  五線がないページ(表紙など)は、縦長なら A4、横長なら A3 とみなす(PDF は記録されたサイズがありえない値のときだけ)
- 向きの自動補正: 横倒し(90°/270°)のページを縦向きに戻す。五線の向きで横倒しを判定し、どちらに回すかは音部記号が五線の左端に来る向きで決める(上下逆は証拠が強いときだけ 180° 回転)。ページごとに左右 90° の手動回転も可
- 見開きの左右分割: 中央 ±10% の範囲で白い綴じ代(なければ綴じ目の影)を検出。分割線はドラッグ/矢印キーで調整、ページごとに分割 ON/OFF
- 傾き補正: 五線の水平線から射影プロファイル法で角度を検出(±5°)。検出結果が届くと、プレビューの紙がスキャンされた傾きから水平へ回る(400ms)。左右ページ別に手動微調整可(下部のスライダー・数値・←→キー。プレビューは CSS transform で即座に追従し、画像処理はスライダーが止まってから行う。緑のガイド線は水平で、五線がこれと平行になれば正しい)
- 背景を白くする(UI 上の名称。内部では白飛ばし): グレー=レベル補正(階調保持)、白黒=適応的二値化、強度調整。
  階調保持では「輪郭強調」(既定オン): 150〜200dpi 程度のスキャンを書き出し解像度まで拡大するとぼやけるため、
  拡大の後で S 字のトーンカーブをかけて輪郭を急峻にする(細い灰色の五線も黒に寄る)
- 余白の自動トリミング → A4 縦に余白を揃えて配置(小さいページを過度に拡大しない)。
  五線を検出し、五線の左右の範囲に収まる塊だけを残す(隣のページの食い込み・余白のスタンプや書き込みを除外)。
  曲名・作曲者・パート名を落とさないよう、最初の五線より上は範囲内なら全部残し、最後の五線より下は 15mm 以内で連なる行(著作権表記・ページ番号)まで残す。
  トリミング範囲の外は白で塗る。紙やスキャナの縁の線(ページの半分以上に伸びる線や枠、写真の紙の輪郭)は内容とみなさない。
  見開きの片側が白紙なら、そのページは出力しない
- 画面: 暗い無彩色の台に楽譜を大きく表示。常時表示は下部の「開く / 傾き / 書き出し」だけで、ページ送り・90°回転・見開き分割・調整/仕上がりの切り替えはプレビュー上部のツールバー、「補正しない（元のまま）」と全ページ共通の設定は「…」。キーボード: ←→ 傾きの微調整(Shift で 0.5°)、PageUp/PageDown ページ移動、Enter ダウンロード
- A4 PDF の書き出し(600/400/300dpi、可逆圧縮のグレースケール。白黒モードは 1bit)。「書き出し」メニューからダウンロード・印刷・新しいタブで開くを選べる。印刷は非表示の iframe から印刷ダイアログを開く(Safari は iframe からの PDF 印刷が不安定なため新しいタブで開く)

## 構成

| 場所 | 役割 |
| --- | --- |
| `src/pipeline/` | 画像処理パイプライン(向き検出・分割・傾き検出・五線検出・白飛ばし・トリミング・A4配置)。UI 非依存で、ブラウザの Worker と Node の検証スクリプトで共用 |
| `src/worker/` | 処理用 Web Worker(OpenCV.js、pdf-lib による PDF 組み立て) |
| `src/lib/` | pdf.js によるラスタライズ(メインスレッド、タイル分割)、状態管理 |
| `src/components/` | UI |
| `scripts/` | UI なしの検証スクリプト |

OpenCV.js と pdf.js の wasm/cmaps は `npm run vendor`(dev/build 前に自動実行)で `public/vendor/` にコピーされ、
`vite.config.ts` の `base`(`/music_sheet_tools/`)配下から読み込まれる。

## 開発

```sh
npm ci
npm run dev          # http://localhost:5173/music_sheet_tools/
npm run build
```

### パイプラインの検証(UI なし)

`samples/` に PDF を置く(著作物を含むため `.gitignore` で除外済み)。

```sh
# 検出結果を画像に描画して debug-out/pipeline/ に出力(分割線=赤、Hough線分=緑、角度)
npm run debug:pipeline -- --filter フェスティバル --pages 2
# 1 ファイルを丸ごと処理して A4 PDF を debug-out/ に出力
npm run debug:export -- フェスティバルTp 600
# 傾きの独立測定(検出値の確認用)
npx tsx scripts/verify-skew.ts フェスティバル.pdf 1 0.06 0.42 4
```

## デプロイ

`main` への push で GitHub Actions(`.github/workflows/deploy.yml`)がビルドして GitHub Pages に公開する。
